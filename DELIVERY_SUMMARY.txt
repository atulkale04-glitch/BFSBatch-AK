DECISION WORKFLOW
================================================================================

1. APPLICATION SUBMISSION
   - User submits loan application via Streamlit or API
   - Input validation (age, income, credit score, etc.)
   - Application stored in database

2. ORCHESTRATION
   - LangGraph validates application data
   - Async parallel agent execution begins

3. APPLICANT PROFILE ANALYSIS
   - Queries ApplicantDB MCP for employment history
   - Calculates income stability score (0-100)
   - Assesses employment risk (low/medium/high)
   - Evaluates credit history

4. FINANCIAL RISK ANALYSIS
   - Queries RiskRulesDB MCP
   - Calculates Debt-to-Income ratio
   - Analyzes credit score risk
   - Detects financial anomalies
   - Generates composite risk score (0-100)

5. LOAN DECISION SYNTHESIS
   - Claude AI synthesizes all evaluations
   - Applies company lending policies
   - Makes final decision: APPROVED / REJECTED / MANUAL_REVIEW
   - Calculates confidence level (0-100%)
   - Identifies key decision factors
   - Generates detailed reasoning

6. COMPLIANCE & NOTIFICATION
   - Generates unique case ID (CASE-YYYYMMDD-XXXXXXXX)
   - Executes decision (approval/rejection/flagging)
   - Sends notification to applicant
   - Logs complete audit trail
   - Records all actions

7. RESULT DELIVERY
   - Complete decision returned to user
   - Risk score, confidence, key factors displayed
   - Reasoning provided for transparency
   - Audit trail available for compliance

API ENDPOINTS

GET /api/v1/applications/{application_id}/decision
  - Get detailed loan decision

GET /api/v1/applications/{application_id}/audit-trail
  - Get complete audit history

GET /api/v1/health

  - Returns: status, timestamp

HOW TO USE
================================================================================

QUICK START - LOCAL DEVELOPMENT:
  1. cd "/home/ubuntu/Desktop/Loan Approval System"
  2. source venv/bin/activate
  3. uvicorn src.main:app --reload
  4. streamlit run ui/streamlit_app.py
  5. Open http://localhost:8501

DOCKER DEPLOYMENT:
  1. docker-compose up --build
  2. Access API at http://localhost:8000
  3. Access UI at http://localhost:8501

API TESTING:
  1. Submit application via API:
     curl -X POST http://localhost:8000/api/v1/applications \
       -H "Content-Type: application/json" \
       -d '{...application data...}'

  2. Check status:
     curl http://localhost:8000/api/v1/applications/{app-id}

  3. View decision:
     curl http://localhost:8000/api/v1/applications/{app-id}/decision

  4. API docs:
     http://localhost:8000/docs
